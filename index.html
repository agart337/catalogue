Welcome to my Javascript archive.

JavaScript is a weird little language. You write a few lines of code and suddenly a button moves, a number changes, or something breaks for absolutely no reason. This website is a collection of the small exercises, and experiments I made while learning JavaScript.

Nothing here is particularly groundbreaking. That’s kind of the point.

Some things work. Some things barely work. Some things probably shouldn’t work at all.
